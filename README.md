## 🚀 Overview

**VOGA AI** is an intelligent fashion technology platform that allows users to virtually try on clothes before purchasing.

Using advanced AI, 3D visualization, and computer vision, users can upload their photo, visualize outfits on realistic avatars, receive personalized styling recommendations, and explore fashion with confidence.

> **Experience online shopping like never before.**

# ⚡ Installation

Clone the repository

```bash
git clone https://github.com/yourusername/VOGA-AI.git
```

Navigate to the project

```bash
cd VOGA-AI
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```
